# x52dev Homebrew tap

This tap packages command-line tools published by [x52dev](https://github.com/x52dev) and [robjtede](https://github.com/robjtede).

## inspect-cert-chain

[`inspect-cert-chain`](https://github.com/x52dev/inspect-cert-chain) prints certificate chains in an OpenSSL-like format for debugging.

```sh
brew install x52dev/tap/inspect-cert-chain
```

## protobug

[`protobug`](https://github.com/x52dev/protobug) interactively inspects protobuf payloads in a terminal.

```sh
brew install x52dev/tap/protobug
```

## dependabot-reviewer

[`dependabot-reviewer`](https://github.com/robjtede/dependabot-reviewer) reviews, rebases, recreates, and merges Dependabot pull requests across repositories.

```sh
brew install x52dev/tap/dependabot-reviewer
```

## xwc

[`xwc`](https://github.com/robjtede/xwc) is a small `wc`-style command-line tool.

```sh
brew install x52dev/tap/xwc
```

The formulas currently provide macOS binaries for Apple silicon and Intel Macs.
